# Practical 1 - Practice Questions

1. Write a program to calculate Simple Interest.
2. Write a program to calculate Area and Perimeter of a Rectangle.
3. Write a program to calculate the Average of five numbers.
4. Write a program to swap two numbers without using a third variable.
5. Write a program to convert Celsius to Fahrenheit.
6. Write a program to calculate the Factorial of a number.
7. Write a program to print the Fibonacci Series.
8. Write a program to check whether a number is an Armstrong Number.
9. Write a program to reverse a string.
10. Write a program to print a pattern using a for loop.
11. Write a program using a structure to store and display Student details.
